# EduQueue — ระบบเรียกคิวออนไลน์

แอปพลิเคชันระบบเรียกคิวแบบเรียลไทม์ (Express + `node:sqlite` + Server-Sent Events)

## ฟีเจอร์หลัก
1. **บัญชีผู้ใช้งานสมัครเองได้ (`user`)** — สมัครสมาชิกและเข้าสู่ระบบด้วยตนเอง
2. **บัญชีคุณครู (`teacher`)** — เรียกคิวถัดไป, เรียกซ้ำ, เสร็จสิ้น, ข้ามคิว, เปิด/ปิดรับคิว, รีเซ็ตคิว, เพิ่มจุดบริการ และเพิ่มบัญชีคุณครู
3. **หน้าผู้ใช้งานลำดับคิวของผู้ใช้** — จองคิว แสดงลำดับคิวปัจจุบัน จำนวนคิวก่อนหน้า และแจ้งเตือนเมื่อถึงคิวแบบเรียลไทม์ พร้อมหน้าจอแสดงผลคิวรวม (Live Board)

## การรันบนเครื่อง (Local)
ต้องใช้ **Node.js >= 22.13.0** (แนะนำ Node 24)

```bash
npm install
npm start
```
เปิดเว็บที่ `http://localhost:3000`

### บัญชีคุณครูเริ่มต้นสำหรับทดสอบ
- `teacher1` / `teacher123`
- `teacher2` / `teacher123`

## การ Deploy ขึ้นออนไลน์ (Render / Railway)
โปรเจกต์ตั้งค่า `engines.node` และ `render.yaml` ไว้เรียบร้อยแล้ว สามารถเชื่อมต่อ GitHub repository นี้บน **Render** (Blueprint / Web Service) หรือ **Railway** เพื่อเปิดใช้งานแบบออนไลน์ได้ทันที
